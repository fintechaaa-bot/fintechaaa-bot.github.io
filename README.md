# 홍길동 Frontend Portfolio

HTML / CSS / JavaScript만으로 만든 정적 포트폴리오 사이트입니다.

## 기능

- 반응형 레이아웃: 모바일 / 태블릿 / 데스크톱
- 다국어: 한국어 / English / 中文 / 日本語
- 다크모드 / 라이트모드
- 프로젝트 7개
- 프로젝트 상세 모달
- 스크롤 진행률
- 섹션 등장 애니메이션
- 모바일 네비게이션
- 언어/테마 선택값 localStorage 저장

## 실행

별도 빌드 과정이 없습니다.

`index.html`을 브라우저에서 열거나 VS Code의 Live Server 등으로 실행하면 됩니다.

## 수정할 부분

`index.html`
- 이름, 이메일, 전화번호, GitHub, Velog

`script.js`
- `translations`: 다국어 문구
- `projects`: 프로젝트 정보

`style.css`
- 색상, 폰트, 레이아웃 등 디자인

## 배포

Netlify, Vercel, GitHub Pages, AWS S3 정적 웹사이트 등에 그대로 배포할 수 있습니다.
